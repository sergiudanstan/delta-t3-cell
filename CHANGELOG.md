# Changelog

All notable changes to this project are documented here. The format follows

## [0.1.1] - 2026-11-26

### Changed
- README and live page now point to [praline-cell](https://github.com/sergiudanstan/praline-cell) and praline-cell-pro. This single-T3 palletizing variant is kept as an archived reference; the repository is archived after this release.

## [0.1.0] - 2026-11-25

First tagged release of the digital twin as published at
https://sergiudanstan.github.io/delta-t3-cell/.

### Added
- Headless page smoke test (`npm test`) run in CI on every push and pull request.
- CI, CodeQL, OpenSSF Scorecard and a tag-triggered release workflow with build
  provenance; Dependabot for actions and npm.
- `SECURITY.md`, `CONTRIBUTING.md` and this changelog.
